## What it is

A high-mobility differential-drive robot designed for wireless control during Robo Soccer at NSECT-2026. The controller runs in a browser so a phone can act as the interface without a dedicated mobile application.

## Technical notes

- ESP32 and Arduino C++
- Four-wheel differential drive
- Robot-hosted Wi-Fi access point
- Browser-based multi-touch controller
- HTML5 Canvas, CSS Grid, and JavaScript on the control interface
- No external router required
